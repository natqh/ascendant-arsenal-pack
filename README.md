# Ascendant Arsenal resource pack

The resource pack for the Ascendant Arsenal Minecraft server plugin (Minecraft Java 26.2,
pack format 88). It contains the weapon models (Emberfall, Tempest Maul, Voidrend), the
effect models, the drawn ability titles, the screen flashes and the HUD sprites.

The server sends it to you when you join, so there's nothing to install by hand.

- Direct link: https://raw.githubusercontent.com/natqh/ascendant-arsenal-pack/main/ArsenalPack.zip
- SHA-1: `18c424738e4d96325b506aafba65a0b91c09c7ed`
