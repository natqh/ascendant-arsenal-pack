# Ascendant Arsenal resource pack

The resource pack for the Ascendant Arsenal Minecraft server plugin (Minecraft Java 26.2,
pack format 88). It contains the Emberfall greatsword model, the Cataclysm meteor and effect
models, the drawn ability titles and the HUD sprites.

The server sends it to you when you join, so there's nothing to install by hand.

- Direct link (used by the server):
  https://raw.githubusercontent.com/natqh/ascendant-arsenal-pack/main/ArsenalPack.zip
- SHA-1: `e92b00c8962fb8319a9674215f9977851f1b196a`
